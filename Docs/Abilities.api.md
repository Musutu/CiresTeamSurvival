## Runtime API (`CireAbilityDB.h`) — for the Skill Shop

```cpp
#include "CireAbilityDB.h"
// Records
const FCireAbilityDef* D = CireAbilityDB::Find(TEXT("ember_lance"));   // or FindByName(TEXT("Ember Lance"))
//   D->Id, Name, Icon ("/Game/UI/Abilities/T_<id>", also CireAbilityIcons::Texture(Id)),
//   D->Types {"DPS","TANK","HEAL"} (hybrids list several), Kind "active|passive|ultimate",
//   School (physical fire cold earth tide holy shadow void poison nature arcane storm),
//   Targeting "self|ally|enemy|aim|passive", CastTime, Range, Radius, Duration,
//   Base (Effect, ManaCost, EnergyCost, Cooldown), Curve, Effects[] (stun/slow/silence/interrupt/
//   healCut/healCutDone/armorBreak/taunt/guard/lethal/cleanse + Duration/Magnitude/Radius/Label),
//   Void (InnerRadius/OuterRadius/... for blink & portal skills), Status "implemented|planned",
//   Champions (who can learn it), SignatureOf (whose identity kit lists it).
const TArray<FCireAbilityDef>& Everything = CireAbilityDB::All();

// Levels (no cap; level 1 = base)
FCireAbilityStats S = CireAbilityDB::EffectiveStats(Id, Level); // Effect, ManaCost, EnergyCost, Cooldown, CastTime, Range...
FString Tip = CireAbilityDB::Describe(Id, Level);             // description + "Level N | 118 damage (+6 next) | 42 mana (+1) | 9.6s cooldown (-0.2s)"

// Champion identity kits (ChampionRoster profile id)
TArray<FString> Shop = CireAbilityDB::PurchasableSkills(ProfileId);        // implemented only (default)
TArray<FString> All  = CireAbilityDB::PurchasableSkills(ProfileId, false); // incl. planned signature skills
bool bOk = CireAbilityDB::CanLearn(ProfileId, Id);
const FCireChampionKit* Kit = CireAbilityDB::Kit(ProfileId);    // Name, PrimaryRole, Roles, Signature, Purchasable
TArray<FString> Opening = CireAbilityDB::OpeningSkills(ProfileId); // the free level-1 pick pool (unchanged rule)

// Buff / debuff modifier summaries for tooltips
FString Line = CireAbilityDB::ModifierSummary(TEXT("heal_cut"));      // "Healing -50%"
const TArray<FCireModifier>* Mods = CireAbilityDB::BuffModifiers(TEXT("armor_broken")); // Stat, Value, Label
```

The pure scaling maths is `Cires::Abilities::Scale(Base, Curve, Level)` in
`Rules/CiresRules.h` (engine-independent, covered by the native rules tests), so a
shop can price levels without touching Unreal types. The opening role skill stays:
the level-1 offer (four primary-role actives) is still generated by the rules; the
shop takes over everything after it. Data changes: edit `Tools/BuildAbilityDB.py`
and rerun it (it validates schools, targeting, effects, void radii and that every
curve is monotone with floors/caps for 200 levels before writing).
