## Runtime API (`CireAbilityDB.h`) — for the Skill Shop

```cpp
#include "CireAbilityDB.h"
// Records
const FCireAbilityDef* D = CireAbilityDB::Find(TEXT("ember_lance"));   // or FindByName(TEXT("Ember Lance"))
//   D->Id, Name, Icon ("/Game/UI/Abilities/T_<id>", also CireAbilityIcons::Texture(Id)),
//   D->Types {"DPS","TANK","HEAL"} (hybrids list several), Kind "active|passive|ultimate",
//   School (physical fire cold earth tide holy shadow void poison nature arcane storm),
//   Targeting "self|ally|enemy|aim|passive", CastTime, Range, Radius, Duration,
//   Base (Effect, ManaCost, EnergyCost, Cooldown), Curve, Effects[] (stun/slow/silence/interrupt/
//   healCut/healCutDone/armorBreak/taunt/guard/lethal/cleanse + Duration/Magnitude/Radius/Label),
//   Void (InnerRadius/OuterRadius/... for blink & portal skills), Status "implemented|planned",
//   Champions (who can learn it), SignatureOf (whose identity kit lists it).
const TArray<FCireAbilityDef>& Everything = CireAbilityDB::All();

// Levels (no cap; level 1 = base)
FCireAbilityStats S = CireAbilityDB::EffectiveStats(Id, Level); // Effect, ManaCost, EnergyCost, Cooldown, CastTime, Range...
FString Tip = CireAbilityDB::Describe(Id, Level);             // description + "Level N | 118 damage (+6 next) | 42 mana (+1) | 9.6s cooldown (-0.2s)"

// Champion identity kits (ChampionRoster profile id)
TArray<FString> Shop = CireAbilityDB::PurchasableSkills(ProfileId);        // implemented only (default)
TArray<FString> All  = CireAbilityDB::PurchasableSkills(ProfileId, false); // incl. planned signature skills
bool bOk = CireAbilityDB::CanLearn(ProfileId, Id);
const FCireChampionKit* Kit = CireAbilityDB::Kit(ProfileId);    // Name, PrimaryRole, Roles, Signature, Purchasable
TArray<FString> Opening = CireAbilityDB::OpeningSkills(ProfileId); // the free level-1 pick pool (unchanged rule)

// Buff / debuff modifier summaries for tooltips
FString Line = CireAbilityDB::ModifierSummary(TEXT("heal_cut"));      // "Healing -50%"
const TArray<FCireModifier>* Mods = CireAbilityDB::BuffModifiers(TEXT("armor_broken")); // Stat, Value, Label
```

The pure scaling maths is `Cires::Abilities::Scale(Base, Curve, Level)` in
`Rules/CiresRules.h` (engine-independent, covered by the native rules tests), so a
shop can price levels without touching Unreal types. The opening role skill stays:
the level-1 offer (four primary-role actives) is still generated by the rules; the
shop takes over everything after it. Data changes: edit `Tools/BuildAbilityDB.py`
and rerun it (it validates schools, targeting, effects, void radii and that every
curve is monotone with floors/caps for 200 levels before writing).

## Crowd control, casts and the new skills (`CireCrowdControl.h`)

| Mechanic | Rule (server; replicated as a buff record) | Record id |
|---|---|---|
| Stun | No casting, attacking, moving, jumping or dodging; cancels a cast; monsters skip their AI. Bosses immune. | `stunned` |
| Silence | No casting (passives and basic attacks still work); cancels a cast. Bosses immune. | `silenced` |
| Interrupt | Cancels the current cast; `lockoutSeconds` locks that spell's school (e.g. Shield Slam: 2s). Monsters use their interruptible flag. | `interrupted` |
| Slow | Existing SlowUntil movement slow. | `slowed` |
| Healing cut | Healing received (`healing_cut`) and/or done (`heal_cut_done`) reduced by X% (magnitude in the record's stacks); cuts multiply. | `healing_cut`, `heal_cut_done` |
| Armor break | Armor x0.5 (hero item armor and monster archetype armor). | `armor_broken` |
| PvP diminishing returns | Stun and silence between champions: full, half, quarter, then immune until 18s pass. | |

- **Timed casts:** `castTime` in Abilities.json (Restoring Light 1.5s, Sanctuary 2s, Purify 1s,
  Wellspring 2s, Renewal 2.5s). Casting sets replicated `ACireHero::CastSkill/CastStartTime/CastEndTime`;
  stun, silence, interrupt, death or a phase change cancel it. The shared cast bars (CireCasts)
  read it through `CireCrowdControl::RegisterCastProvider` (heals show green; interrupted/silenced
  flashes are detected automatically).
- **Ability effects:** each ability's `effects` (stun/silence/interrupt/healCut/healCutDone/armorBreak)
  apply automatically when its hits land (`OnAbilityHit`, matched by display name). Current users:
  Shield Slam (interrupt + 2s lockout), Grave Line (2s silence), Blight Sigil (-50% healing received,
  6s), Seismic Reprisal (1s stun), Decimating Strike (armor break).
- **Void rift** (`void` in Abilities.json; Shadow Step now; planned blink/portal skills carry radii):
  centred on the destination, enemies inside `innerRadius` (180cm) are stunned 1s, enemies in the ring
  up to `outerRadius` (420cm) are slowed 40% for 2.5s, everyone in either zone takes void damage and
  the caster mends 5% max health. The ability-vfx agent can draw both circles from these radii.
- **Executioner** (passive, DPS; signature of Ranger, Lancer and both Red-Moon Berserkers): ready when
  learned and every 5 minutes after use (`executioner_ready` record). The next basic attack kills an
  ordinary monster; a boss takes a normal hit and the charge is kept; a champion takes
  max(normal hit, 30% of max health). **PvP choice: 30% of max health**, documented here.
- **Decimating Strike** (active, TANK/DPS; signature of Drakish Footman, Felfire Golem, Blood-Oath
  Chieftain, melee Red-Moon Berserker): 40 energy, 300s cooldown, melee range. Kills an ordinary
  monster; bosses take 150 + 2x primary; champions take max(that, 30% max health). All enemies within
  5m lose 50% armor for 10s.
- Maths: `Cires::CC` (DiminishedDuration, ClassifyVoidZone, ApplyHealingCut, ArmorAfterBreak,
  ExecuteDamage) in the rules module, covered by the native rules tests; runtime smoke
  `CIRE_CC_PASS` in the in-engine checks.
