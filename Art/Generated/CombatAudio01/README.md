# Cire Combat Audio 01

Nine original deterministic synthesized mono combat sounds, authored by BuildSpellContent.py. 48 kHz, 16-bit PCM, softened onset/tail, normalized peak below -2 dBFS. No external samples.

Spatial attenuation is configured on each local presentation audio component (160 cm inner radius, 1800 cm falloff). Shared concurrency limits combat presentation to 16 voices. Confirmed-hit audio is only emitted by authoritative combat events; misses and dodges have visual text without impact sound. These are original gameplay cues, pending a final sound-design/mixing pass.
